# Obtain the original dataset

Download https://jse.amstat.org/v19n3/decock/AmesHousing.txt and save it here as `AmesHousing.txt`. Keep the bytes and tab-separated format unchanged. Download the feature documentation from https://jse.amstat.org/v19n3/decock/DataDocumentation.txt if needed.

The dataset is not included. Source redistribution rights have not been established; use the original source and retain attribution. Read the study at https://jse.amstat.org/v19n3/decock.pdf.

Reference SHA-256 for the original text file:
`6cfe6cb525ba437de428653a1040e2aed7d696640bf75203786a6d7a0e67cfcc`

Notebook 1 creates `data/processed/train.csv`, `test.csv` and a split manifest. These are local generated outputs. To run the included application you do not need the raw data.
